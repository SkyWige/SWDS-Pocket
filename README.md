# SWDS Pocket

Android-приложение для **SWDS** (SkyWige Digital Server): сервер в кармане.

- 🔔 **Уведомления от SWDS** — мгновенно (постоянное соединение) или раз в 15 минут; вопросы с кнопками и ответом прямо из шторки; «Найти телефон».
- 📂 **Общая папка телефон ↔ ПК** — «Отправить в SWDS» из любого приложения, раскладка по папкам (Документы, Изображения… или «🪄 само»), синхронизация папок телефона с компьютером в обе стороны, как в Syncthing (или только туда / только обратно; без копий-дублей, удалённое — в версиях и корзине 30 дней), всё из «Телефон/На телефон» само скачивается в Загрузки/SWDS. Текст и ссылки — в буфер обмена в обе стороны.
- 🧩 **Виджеты** на домашнем экране: «Сегодня», быстрые действия, уведомления, общая папка и любые виджеты SWDS Desktop, включая свои.
- 🎨 **Темы** SWDS — приложение и виджеты красятся в тему сервера (включая автосмену светлая/тёмная).
- 🧭 **Все модули** SWDS, ассистент, команды и планировщик — в приложении; плитка в шторке для любимой команды.
- 🔋 Заряд, зарядка, Wi-Fi и местоположение → события для автоматизаций SWDS.

- 🔍 **Автопоиск SWDS** в домашней сети: при привязке и сам, если роутер выдал компьютеру новый IP.

## Установка
1. Скачайте APK из [последнего релиза](https://github.com/SkyWige/SWDS-Pocket/releases/latest) и установите.
2. В SWDS откройте модуль **«📱 Телефон»** → «Показать QR-код».
3. В приложении нажмите «Сканировать QR-код».

## Сборка
APK собирается GitHub Actions при каждом пуше в `main` и публикуется в релизах.
Подпись: секреты репозитория `SIGNING_KEYSTORE_B64` (keystore в base64) и `SIGNING_PASSWORD`.
Без них используется публичный запасной ключ — подходит только для проб.
